# 个人信息台构建器

把一份素材库变成一个**双击就能用、离线能看、数据在自己手上**的个人信息台。

输出是一个单文件 HTML：零外链、零依赖、零后端。断网也能开，数据不出本机。

没有素材库也没关系——包里带了深度访谈脚本（`references/interview-guide.md`），
按它问三轮，需求就落成了配置。

## 零修改先跑通（复刻「秋招信息工作台」同款）

```bash
bash build_my_desk.sh
```

脚本直接 build 包里的 `我的素材库/` → 生成 `我的信息台.html` → 自动打开。
**这个 `我的素材库/` 就是一份已经填好的、可 build 的素材库**，别人装上就能一键得到成品，
不必先理解字段。想先看成品长什么样，直接开 `examples/example-qiuzhao-desk.html`。

## 三步做自己的台子

```bash
# 1. 生成一份空白素材库（复制 assets/素材库模板/ 到 ./我的素材库）
python scripts/build_desk.py --init ./我的素材库

# 2. 填素材库（Excel 直接编辑 02-数据.csv；列定义在 01-字段定义.csv；视图在 03-视图配置.json）

# 3. 生成工作台
python scripts/build_desk.py --lib ./我的素材库 --out 我的信息台.html
```

双击 HTML 就能看。不需要起服务，不需要装任何东西。

别人装好这个 skill，照三步就能从零复刻成品，无需任何外部页面。

## 它解决什么问题

「我有一批东西，想做成一个能筛选、能标状态、能导出、能天天看的台子。」

求职岗位池 · 客户名单 · 论文文献库 · 书影音清单 · 项目看板 · 订阅与到期提醒……

## 目录

```
SKILL.md                            给 Agent 看的执行流程
build_my_desk.sh                   一键：build 我的素材库 → 我的信息台.html
我的素材库/                         已填好的可 build 素材库（别人直接 build 这个）
assets/素材库模板/                   空白素材库（--init 复制它）
references/interview-guide.md       深度访谈执行手册
references/html-checklist.md        页面骨架 / 视觉铁律 / 交付前自检
scripts/build_desk.py               主生成器
script/embed_data.py               只更新已有 HTML 的内嵌数据
examples/lib-qiuzhao-sample/        填好的示例素材库（输入，和「我的素材库」同款）
examples/example-qiuzhao-desk.html  它生成出来的页面（输出）
```

**三种角色分清楚**：
- `我的素材库/` + `build_my_desk.sh` → **拿来就 build**，立刻得到同款秋招台子
- `assets/素材库模板/` → 空白模板，`--init` 复制它给自己填
- `examples/` → 纯参考（输入样例 / 输出页面），不一定要动

## 素材库长什么样

四个纯文本文件，Excel 就能编辑：

| 文件 | 作用 |
|---|---|
| `01-字段定义.csv` | 有哪些列，每列是什么类型（text/date/link/tags/number） |
| `02-数据.csv` | 数据行，表头 = 字段 key |
| `03-视图配置.json` | 标题、配色、主键、状态流转、左上角数字 |
| `00-访谈记录.md` | 需求存档，不参与生成 |

完整字段说明见 `assets/素材库模板/填表说明.md`。

## 成品自带

侧栏 KPI + 筛选 · 顶部搜索 · 点表头排序 · 状态流转 · 备注 ·
响应式（窄屏表格自动转卡片）· 导出 JSON/CSV 回环 · 数据内嵌（`file://` 双击即见）。

## 三条硬铁律

1. **数据必须内嵌**。`file://` 下 `fetch` 本地文件会被 CORS 拦，兜底的"自动弹文件框"
   又会被浏览器拦（须用户手势）→ 不内嵌就是 0 条。生成器已默认内嵌。
2. **稳定 id 用业务主键**（配置里的 `idFields`）。用随机数会让每次刷新后的状态对不上。
3. **全内联零外链**。CDN 一挂，离线就废了。

## 边界

这个 skill 做的是**数据的组织与呈现**，不是数据的获取。素材应来自你自己有权使用的渠道：

本地文件 · 表格 · 数据库导出 · 手工录入 · 对方明确开放的数据导出或接口。

不做登录态绕过、不做签名复刻、不做频率规避。对方只提供网页时，优先自己导出 CSV/Excel 再喂进来。

**数据从哪来（仅授权渠道）**：站点自带导出/订阅（国聘网、学校就业网、应届生网多支持 RSS 或表格导出）→ 直接喂 `02-数据.csv`；或手动把网页条目整理成表格；或仅用站点明文开放、条款允许的 API。你私人的取数脚本留在本地项目，不要打进这个公开 skill。

## 要求

Python 3.8+，零第三方依赖（只用标准库）。

生成页面本身不需要任何运行时——拿到 HTML 就能用。
