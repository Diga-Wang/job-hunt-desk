# 单文件 HTML 信息台 · 构建清单

数据管道（载入/选文件/IndexedDB 句柄/导出回环/jsdom 测试）的**完整代码**
在 skill `local-html-json-loader` 里，本篇只写「页面长什么样 + 交付前自检」，
两边配合用，不重复。

## 页面骨架

```
aside 侧栏（品牌 + 导航 + 数据来源/更新时间 + 「点击更新」按钮 + 清空/导出）
main
 ├ 顶部：日期 + 4 个统计卡（总数 / 进行中 / 待处理 / 已截止）
 ├ 今日要处理（逾期红、临期琥珀，点击跳详情）
 ├ 主体分区（Tab）：① 数据池（表格+筛选+排序）② 状态跟踪 ③ 经历/素材库 ④ 字段说明
 └ 空状态：明确写「点『点击更新』载入 xxx.json，或直接『新增』」
```

- 分区用 Tab 切换，别塞一屏；主体表格容器给固定 id（如 `#poolBody`），验证时好数行数
- 筛选器：关键词 + 类别 + 批次 + 时间范围，全部 `onchange/oninput` 触发重渲染
- 表头可排序（`th.sortable` + `data-sort`），点击切换升降序

## 视觉铁律

- **全内联零外链**：CSS/JS 全在文件里，图标图表一律内联 SVG。CDN 一挂页面就废
- **响应式**：≤760px 表格转卡片 —— `thead{display:none}` + `td{display:flex}` + `td::before{content:attr(data-l)}`
- **输入框 ≥16px**，否则 iOS 聚焦自动放大
- 不用 emoji 图标（跨平台字形不一致），用 SVG
- 无数据时显示空状态引导，不要白屏

## 状态跟踪层（若要跟踪）

```js
var STATUS = [
  { key:'not_applied', label:'未投递', color:'#98A6B3' },
  { key:'applied',     label:'已投递', color:'#034EA2' },
  { key:'interview',   label:'面试中', color:'#B8860B' },
  { key:'offer',       label:'offer',  color:'#1F7A4D' },
  { key:'rejected',    label:'已拒绝', color:'#B23A2E' }
];
```
- 状态/投递日期/备注存 `localStorage`，**按稳定 id 关联**，与只读的外部 JSON 分离
- 合并时 `MANUAL` 优先，外部 JSON 更新不会冲掉用户编辑
- 「今天要处理」= 截止时间距今 ≤N 天 或 已逾期（逾期用红色）

## 交付前自检

- [ ] 双击（`file://`）打开，数据直接可见，无需任何操作
- [ ] 渲染行数 == 数据条数（Playwright `file://` 断言）
- [ ] `evaluate` 都用的箭头函数（`() => ...`）
- [ ] 事实字段（截止/金额）没编造，未公布就是空
- [ ] 导出 → 重导入 → 字段条数不变（回环测试）
- [ ] 清空有二次确认，且清完内存里的数据一起没
- [ ] 窄屏下表格变卡片，无横向滚动
- [ ] 断网打开仍正常（全内联验证）

## 已知假报警

`file://` 下控制台必有 CORS 报错（`fetch` 本地文件被拦）—— 内嵌数据已接管，
属预期无害，**不要当成 bug 去修**。
