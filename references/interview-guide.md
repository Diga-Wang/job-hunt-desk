# 深度访谈执行手册（给 Agent）

当用户**手上没有结构化素材库**时，按本手册分三轮问，把答案落成 `assets/素材库模板/`
里的文件（`--init` 会复制一份空白模板给用户）。已有素材库（CSV/Excel/JSON/导出）
则跳过，直接进 SKILL.md 第 2 步填 `02-数据.csv`。

## 总规则

- 能推断的别问；拿不准的给选项，不要开放式散问。
- 用户说「你看着办」→ 直接套下方**兜底默认**，别追问。
- 每轮 3–4 题，问完一轮就落文件，不要攒一大堆再填。
- 访谈内容落进 `00-访谈记录.md`（需求存档）；结构化字段进 `02-数据.csv`，视图进 `03-视图配置.json`。

## 第一轮 · 定位（决定要不要状态列）

1. 你手上这批东西是什么？（岗位 / 客户 / 论文 / 书影音 / 项目 / 其它）
2. 现在最难受的是什么？（找不到 / 记不住进展 / 错过 deadline / 只是想看全）
3. 做出来你最常在它上面做什么？（翻找浏览 / 推进某条 / 盯到期）

→ 推导：`03-视图配置.json` 的 `status.enabled`
- 翻找、看全 → `false`（纯浏览，关状态列）
- 推进、盯 deadline → `true`（开状态列 + 备注 + 截止提醒）

## 第二轮 · 结构（决定主键与列）

1. 一行代表什么？（一个岗位 / 一个客户 / 一条文献）
2. **哪几个字段合起来能唯一确定一行？**（最关键，决定 `idFields`）
   - 秋招：单位名称 + 岗位/项目
   - 客户：公司 + 联系人
   - 文献：标题 + 来源
3. 你想要哪些列？（标题 / 分类 / 链接 / 截止时间 / 备注 / 金额 …）
4. 哪些列要能筛选？哪些要能搜索？

→ 推导：在 `01-字段定义.csv` 写列（key,label,type,width,filter,sort,search），
把 `idFields` 写进 `03-视图配置.json`。

## 第三轮 · 行为（决定 KPI 与风格）

1. 左上角最想看哪几个数？（总数 / 待办数 / 3 天内到期 / 某类汇总）
2. 风格偏好？（商务沉稳 / 温柔生活 / 极简黑白）
3. 主要在手机还是电脑上看？（手机 → 表格要能转卡片，输入字号 ≥16px）

→ 推导：`03-视图配置.json` 的 `kpis` 与 `theme`。

## 兜底默认（用户说你看着办 / 答不上来时）

| 项 | 默认 |
|---|---|
| `idFields` | 取前两列拼接，重复就加第三列 |
| `status.enabled` | `true`（大多数人要推进/盯进度） |
| 列 | 标题 / 分类 / 链接 / 截止时间 / 备注 |
| `kpis` | 总数 + 截止时间内未处理数 |
| `theme` | `mckinsey`（最稳妥） |
| 截止标红 | 距今 ≤3 天；过期置灰 |

## 落地示例（秋招场景）

访谈得到：「我想管秋招岗位，怕错过截止，按单位和岗位区分，想看总数和 3 天内到期。」

→ 写进 `assets/素材库模板/`：
- `01-字段定义.csv`：单位名称 / 岗位/项目 / 类别 / 批次 / 截止时间 / 来源 / 公告链接
- `02-数据.csv`：每行一个岗位，表头对齐上面的 key
- `03-视图配置.json`：`idFields=["单位名称","岗位/项目"]`，`status.enabled=true`，
  `kpis=[{op:"count"},{op:"dueWithin",days:3,key:"截止时间"}]`，`theme.name="mckinsey"`
- 跑 `python scripts/build_desk.py --lib ./我的素材库 --out 我的信息台.html`
