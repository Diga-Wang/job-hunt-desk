# 深度访谈记录

这份文件**不参与生成**，它的作用是：把「我到底想要一个什么样的台子」想清楚。
填完交给 Agent，它会把答案落成 `03-视图配置.json`。

如果你是被访谈的一方，直接照下面的问题口述即可，让 Agent 帮你填。

---

## 一、定位：这个台子是干嘛的

**Q1. 你手上现在有一批什么东西？**

（例：387 家公司的招聘公告 / 收藏的 200 篇论文 / 在跟的 30 个客户）

> 答：

**Q2. 你现在怎么看这批东西？哪里难受？**

（例：散在微信收藏和 Excel 里 / 每次找都要翻半天 / 不知道哪些快截止了）

> 答：

**Q3. 做出来之后，你最常做的事是哪一件？**

A. 大海捞针式翻找、筛选　　B. 标记进度、推进流程
C. 盯着 deadline 别错过　　D. 只是想有个地方能一眼看全

> 答：

> **判定**：选 A 或 D → 状态列可以关掉；选 B 或 C → 状态列必须开，且 C 还要保留一个日期字段做「到期提醒」。

## 三、行为：你希望它长什么样

**Q8. 左上角想看哪几个数字？**

常见的：总条目 / 各状态分别多少 / 7 天内到期 / 某个数值求和 / 去重计数

> 答：

**Q9. 风格偏好？**

□ 麦肯锡商务（深藏青侧栏，冷、专业）
□ 温柔个人（米白 + 淡紫，暖、松弛）
□ 极简黑白（无彩色，克制）

**Q11. 数据现在在哪？**

□ 没有，我要手工录　□ Excel/CSV　□ JSON　□ 从某个系统导出

# Agent 落配置对照表

访谈填完后，按下表把答案写进 `03-视图配置.json`：

| 访谈题 | 落到配置字段 |
|---|---|
| Q1 | `title` / `subtitle` |
| Q3 选 A/D | `status.enabled = false` |
| Q3 选 B/C | `status.enabled = true` |
| Q5 | `idFields`（数组，2 个以上字段） |
| Q6 | `columns[]`（key/label/type/width/filter/search） |
| Q7 | `status.options`（有序数组） |
| Q8 | `kpis[]`（op: count / countWhere / dueWithin / sum / distinct） |
| Q9 | `theme.name`（mckinsey / warm / ink） |
| Q10 | 自动支持，无需配置 |

**type 可选值**：`text` 文字 · `date` 日期 · `link` 链接 · `tags` 标签（逗号分隔，可筛选） · `number` 数字
