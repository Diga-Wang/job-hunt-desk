# 素材库填表说明

这个目录就是你的台子的**全部原料**。填完跑一条命令就出成品，不需要懂前端。

```
python build_desk.py --lib ./本目录 --out 我的信息台.html
```

---

## 四个文件，哪些必填

| 文件 | 必填 | 作用 |
|---|---|---|
| `03-视图配置.json` | ✅ | 标题、配色、主键、状态流转、左上角数字 |
| `01-字段定义.csv` | ✅ | 有哪些列、每列是什么类型 |
| `02-数据.csv` | ✅ | 实际数据行（可先用 Excel 编辑） |
| `00-访谈记录.md` | ❌ | 需求来源，不参与生成，留着复盘用 |
| `02-数据-示例.csv` | ❌ | 格式参考，看完删掉 |

`01-字段定义.csv` 存在时，会**覆盖** `03-视图配置.json` 里的 `columns`。
想只用 JSON 管一切，把 `01` 删掉即可。

## 01-字段定义.csv

| 列 | 填什么 | 说明 |
|---|---|---|
| `key` | 字段英文名/数据列名 | 必须和 `02-数据.csv` 的表头**完全一致** |
| `label` | 界面上显示的中文名 | |
| `type` | `text` / `date` / `link` / `tags` / `number` | 见下表 |
| `width` | 列宽像素 | 不填默认 120 |
| `filter` | `true` / `false` | 是否在左侧生成下拉筛选 |
| `sort` | `true` / `false` | 是否可点表头排序 |
| `search` | `true` / `false` | 是否参与顶部搜索 |

**type 说明**

| type | 用途 | 渲染效果 |
|---|---|---|
| `text` | 普通文字 | 直接显示 |
| `date` | 日期 | **3 天内到期标红**，已过期变灰 |
| `link` | 网址 | 显示「打开」，新窗口跳转 |
| `tags` | 多标签 | 逗号分隔，渲染成小圆角标签，可筛选 |
| `number` | 数字 | 右对齐、按数值排序 |

## 02-数据.csv

- 用 Excel / Numbers 编辑最方便，另存为 **CSV UTF-8** 即可
- 表头必须是字段的 `key`，和 `01` 对得上
- 空着就行，**不要编造事实**（截止日期、金额、链接这类留空比填错强）
- 列里如果有逗号，用双引号包起来（Excel 会自动处理）

## 03-视图配置.json

### idFields —— 最重要的一项

哪几个字段合起来能**唯一确定一行**。它决定你标记的状态会不会串台。

```json
"idFields": ["单位名称", "岗位"]
```

- 只写一个字段，而那个字段会重复 → 同名的行状态会互相覆盖
- 生成时会检查唯一性，有重复会警告你加一列

### status —— 流转步骤

```json
"status": {
  "enabled": true,
  "options": ["未开始", "进行中", "已完成", "已放弃"],
  "default": "未开始"
}
```

- `enabled: false` → 整张表不出现状态列和备注列，纯浏览模式
- 顺序就是下拉框里的顺序
- 状态和备注存在浏览器 localStorage，**换数据不会丢**（只要 idFields 没变）

### kpis —— 左上角数字

| op | 含义 | 需要额外字段 |
|---|---|---|
| `count` | 总条数 | — |
| `countWhere` | 某字段等于某值的条数 | `key`, `eq` |
| `dueWithin` | N 天内到期 | `key`（日期列）, `days` |
| `sum` | 数值求和 | `key`（数字列） |
| `distinct` | 去重计数 | `key` |

统计状态时 `key` 写 `__status`：

```json
{ "label": "进行中", "op": "countWhere", "key": "__status", "eq": "进行中" }
```

### theme —— 配色

| name | 观感 | 适用 |
|---|---|---|
| `mckinsey` | 深藏青侧栏 + 蓝色强调 | 求职、客户、项目、汇报 |
| `warm` | 米白 + 淡紫侧栏 + 珊瑚点缀 | 书影音、灵感、生活 |
| `ink` | 黑白 + 一抹蓝 | 作品集、档案、极简 |

想精确控制颜色，覆盖单个变量：

```json
"theme": {
  "name": "mckinsey",
  "vars": { "accent": "#C0392B", "radius": "2px" }
}
```

可覆盖：`sideBg` `sideFg` `sideSub` `accent` `bg` `fg` `line` `chip` `radius`

## 常见报错

| 报错 | 原因 | 怎么修 |
|---|---|---|
| 找不到 03-视图配置.json | 目录指错了 | 确认 `--lib` 指向本目录 |
| 页面打开是 0 条 | 02-数据.csv 只有表头 | 填数据行 |
| 列全是英文 / 顺序不对 | 01 的 key 和 02 表头不一致 | 两边对齐 |
| KPI 显示「—」 | op 写错了，或 key 不存在 | 检查 `kpis` 里的 `op` 拼写 |

## 生成之后

- 双击 HTML 就能看，**离线可用**，不需要起服务
- 点「更新数据」可以临时换成别的 CSV/JSON，不改源文件
- 「导出 JSON」会把你的状态和备注一起带出来，换电脑也不丢
- 数据更新后，重新跑一遍生成命令即可覆盖
