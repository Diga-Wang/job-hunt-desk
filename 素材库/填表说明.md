# 素材库填写说明

`素材库/` 里的两个 JSON 是给你（或下载这个 skill 的人）放**自己数据**的。
页面打开时内置了示例数据；想换成自己的，就改这两个文件再「导入」。

## 1. jobs.json（岗位数据）

整体结构：

```json
{
  "updatedAt": "2026-09-01",
  "jobs": [
    {
      "单位名称": "某某公司",
      "岗位/项目": "某某岗位",
      "类别": "国企 / 事业单位 / 互联网 / 外企 / 其他",
      "批次": "提前批 / 正式批 / 补录 / 社招 / 秋招 / 宣讲会/双选会",
      "报名截止时间": "YYYY-MM-DD（未公布留空字符串）",
      "来源": "猎聘 / BOSS直聘 / 公司官网 / 公众号",
      "发布时间": "YYYY-MM-DD（可留空）",
      "公告链接": "完整 URL（可留空）",
      "薪资": "12-18K·14薪 / 面议（可留空，留空不显示薪资标签）",
      "专业要求": "逗号分隔可写多个专业（可留空，留空视为未标明，不参与硬性匹配）",
      "学历要求": "本科及以上 / 硕士及以上（配合「我的资质」做硬性要求核对）",
      "经验要求": "应届生 / 1-3年 / 3年以上（可留空）",
      "招聘人数": "数字或文本（可留空）",
      "部门": "文本（可留空）",
      "专业匹配": "匹配 / 不符 / 未标明（可手工判定，也可留空由页面按「我的资质」自动计算）",
      "投递状态": "未投递 / 已投递 / 笔试中 / 面试中 / offer / 已拒绝（留空视为未投递；页面里手动改过状态后不会再被这个字段覆盖）",
      "投递日期": "YYYY-MM-DD（配合「投递状态」使用，可留空）"
    }
  ]
}
```

- 事实类字段（截止日期、链接、薪资、专业/学历要求）没拿到就留空，**禁止编造**。
- `jobs` 是数组，一行一条岗位。
- 除「单位名称」「岗位/项目」外都是可选字段；新版新增的 7 个字段（薪资 / 专业要求 / 学历要求 / 经验要求 / 招聘人数 / 部门 / 专业匹配 / 投递状态 / 投递日期）留空完全不影响老数据继续使用。

## 2. experience.json（经历库）

顶层字段：

| 字段 | 说明 |
|---|---|
| `items` | 经历条目数组，每条含 标题/组织/时期/方向标签/背景/动作/结果/量化/待补/关键词 |
| `优势` | 字符串数组，如 `["条理性","落地意识"]` |
| `风险追问` | 数组，每条 `{问题, 要点[]}` |
| `教育背景` | 数组，每条 `{学校, 学位, 形式, 时期, 毕设}` |
| `工具技能` | 数组，每条 `{类别, 工具[], 备注}` |
| `能力标签` | 数组，每条 `{标签, 说明, 支撑经历[]}` |
| `转型叙事` | 对象 `{一句话, 为什么转行, 两分钟自我介绍}` |
| `核实修正` | 数组，每条 `{项, 原表述, 问题, 修正后}` |

`items` 里每条经历：

```json
{
  "id": "e1",
  "标题": "校园招聘项目统筹",
  "组织": "某某单位",
  "时期": "2024",
  "方向标签": ["运营"],
  "背景": "一句话背景",
  "动作": "你做了什么",
  "结果": "产出",
  "量化": "可量化数字",
  "待补": "面试易被追问、还没说清的点",
  "关键词": ["统筹", "SOP", "看板"]
}
```

`关键词` 是 JD 对照里「经历库命中」的依据——JD 里出现这些词就会被标中。

## 3. 怎么导入

打开 `秋招信息工作台（共享版）.html` 后：

- **岗位**：左侧「点击更新」→ 选中你改好的 `jobs.json`
- **经历库**：「经历库」页 →「导入 experience.json」→ 选中你改好的 `experience.json`

导入后页面立即显示你的数据；可继续在页面里增删改。

## 4. 我的资质（新增，不需要 JSON 文件）

岗位池右上角「我的资质」按钮打开一个表单：填你的最高学历、专业/方向、工作年限、政治面貌、持有证书等。

- 填好后，岗位池里每条岗位会按「学历要求 / 专业要求」等字段实时核对，标出「专业匹配」徽标（匹配 / 不符 / 未标明）和「硬性不符」提示。
- 支持筛选「只看匹配度≥60%」「隐藏硬性不符」。
- 这部分数据只存在你浏览器的 localStorage 里，不写进 `jobs.json`，不用维护额外文件。

## 5. JD 多岗位对比（新增）

新增的「JD 对比」页面：把多条岗位的完整 JD 粘贴进去（岗位之间用单独一行的 `====` / `---` / `***` 分隔），会自动抽取单位 / 岗位 / 城市 / 薪资 / 截止时间 / 核心要求，排成表格并排对比，可切换看每条 JD 原文。只做抽取和摆放，不打分、不生成文案，判断权在你。抽错或漏抽的字段可以直接在表格里改，自动存本地。
