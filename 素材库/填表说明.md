# 素材库填写说明

`素材库/` 里的两个 JSON 是给你（或下载这个 skill 的人）放**自己数据**的。
页面打开时内置了示例数据；想换成自己的，就改这两个文件再「导入」。

## 1. jobs.json（岗位数据）

整体结构：

```json
{
  "updatedAt": "2026-09-01",
  "jobs": [
    {
      "单位名称": "某某公司",
      "岗位/项目": "某某岗位",
      "类别": "国企 / 事业单位 / 互联网 / 外企 / 其他",
      "批次": "提前批 / 正式批 / 补录 / 社招 / 秋招 / 宣讲会/双选会",
      "报名截止时间": "YYYY-MM-DD（未公布留空字符串）",
      "来源": "猎聘 / BOSS直聘 / 公司官网 / 公众号",
      "发布时间": "YYYY-MM-DD（可留空）",
      "公告链接": "完整 URL（可留空）"
    }
  ]
}
```

- 事实类字段（截止日期、链接）没拿到就留空，**禁止编造**。
- `jobs` 是数组，一行一条岗位。

## 2. experience.json（经历库）

顶层字段：

| 字段 | 说明 |
|---|---|
| `items` | 经历条目数组，每条含 标题/组织/时期/方向标签/背景/动作/结果/量化/待补/关键词 |
| `优势` | 字符串数组，如 `["条理性","落地意识"]` |
| `风险追问` | 数组，每条 `{问题, 要点[]}` |
| `教育背景` | 数组，每条 `{学校, 学位, 形式, 时期, 毕设}` |
| `工具技能` | 数组，每条 `{类别, 工具[], 备注}` |
| `能力标签` | 数组，每条 `{标签, 说明, 支撑经历[]}` |
| `转型叙事` | 对象 `{一句话, 为什么转行, 两分钟自我介绍}` |
| `核实修正` | 数组，每条 `{项, 原表述, 问题, 修正后}` |

`items` 里每条经历：

```json
{
  "id": "e1",
  "标题": "校园招聘项目统筹",
  "组织": "某某单位",
  "时期": "2024",
  "方向标签": ["运营"],
  "背景": "一句话背景",
  "动作": "你做了什么",
  "结果": "产出",
  "量化": "可量化数字",
  "待补": "面试易被追问、还没说清的点",
  "关键词": ["统筹", "SOP", "看板"]
}
```

`关键词` 是 JD 对照里「经历库命中」的依据——JD 里出现这些词就会被标中。

## 3. 怎么导入

打开 `秋招信息工作台（共享版）.html` 后：

- **岗位**：左侧「点击更新」→ 选中你改好的 `jobs.json`
- **经历库**：「经历库」页 →「导入 experience.json」→ 选中你改好的 `experience.json`

导入后页面立即显示你的数据；可继续在页面里增删改。
